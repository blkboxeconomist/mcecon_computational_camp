# Homework 12 — Guided project

The guided project is the capstone. See the week 12 lecture
(`lectures/L12_project/project.ipynb`) for the full specification.

This folder is **not** a single notebook — it's where you submit:

- the URL of the GitHub repository you create (in `submission.md`)
- a PDF of your writeup (`paper.pdf`)
- your completed `notebooks/analysis.ipynb` (copied here or linked)

## Submission

Create `submission.md` in this folder with the structure:

```md
# Camp project submission — <your name>

## Repository
<github URL>

## Commit you want graded
<commit SHA>

## Notes for the grader
<any deviations from the spec, stretch goals attempted, etc.>
```

Upload `submission.md` + `paper.pdf` to the course portal.
