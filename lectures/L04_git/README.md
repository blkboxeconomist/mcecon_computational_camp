# Week 4 — Git + version control

## Learning objectives

By the end of this lecture, students should be able to:

- Explain why version control exists and what a commit is
- Initialize a repo, stage files, and commit
- Use branches, merges, and resolve a simple conflict
- Push to and pull from a remote (GitHub)
- Open a pull request on a collaborator's repo
