# Week 9 — AI-assisted coding + debugging + tiny OOP

## Learning objectives

By the end of this lecture, students should be able to:

- Use Claude Code, Cursor, or Copilot effectively for research code
- Read a Python traceback and locate the root cause
- Use `try`/`except` and `breakpoint()` to diagnose bugs
- Define a simple `@dataclass` and call methods on an instance
- Decide when AI assistance helps versus hurts
