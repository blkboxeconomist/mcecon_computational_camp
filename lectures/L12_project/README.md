# Week 12 — Guided project

## Learning objectives

By the end of this lecture, students should be able to:

- Combine the tools from weeks 1–11 into one end-to-end project
- Version-control an evolving codebase on a branch
- Write tests that protect the core logic
- Produce a short LaTeX writeup of results
- Reflect on what went well and where tools helped

## Prerequisite weeks

Weeks 1–11
