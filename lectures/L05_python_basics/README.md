# Week 5 — Python basics

## Learning objectives

By the end of this lecture, students should be able to:

- Assign variables and reason about types (`int`, `float`, `str`, `bool`)
- Use arithmetic, comparison, and boolean operators
- Manipulate strings with f-strings, slicing, and common methods
- Use `print` and `input` for simple I/O
- Understand truthiness and the difference between `==` and `is`
