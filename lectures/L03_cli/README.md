# Week 3 — Command line, shells, terminal

## Learning objectives

By the end of this lecture, students should be able to:

- Navigate the filesystem with `cd`, `ls`, `pwd`
- Read, search, and filter files with `cat`, `grep`, `head`, `tail`
- Use pipes and redirection to compose commands
- Understand environment variables and shell config (`~/.zshrc`)
- Preview `ssh` for remote machines
