# Week 2 — Markdown + Jupyter notebooks

## Learning objectives

By the end of this lecture, students should be able to:

- Write prose, headings, lists, and code blocks in Markdown
- Typeset math with `$...$` and `$$...$$`
- Navigate Jupyter notebooks: cells, kernels, edit vs. command mode
- Recognize hidden state and out-of-order execution bugs
- Export notebooks to HTML or PDF
