# Week 7 — Collections

## Learning objectives

By the end of this lecture, students should be able to:

- Use lists, tuples, dictionaries, and sets appropriately
- Index and slice sequences
- Iterate over collections with `for` and unpack items
- Write list, dict, and set comprehensions
- Pick the right data structure for a given task
