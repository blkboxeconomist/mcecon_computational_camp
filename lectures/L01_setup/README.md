# Week 1 — Getting set up: `uv`, Python, editor, Jupyter

## Learning objectives

By the end of this lecture, students should be able to:

- Install `uv` on their machine and understand what it is
- Use `uv python install` to pin a Python version
- Create a uv-managed project with `uv init`
- Add dependencies with `uv add` and run code with `uv run`
- Choose and configure a text editor (VS Code or Zed)
- Launch Jupyter from their uv environment
