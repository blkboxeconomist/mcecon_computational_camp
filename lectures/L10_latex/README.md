# Week 10 — LaTeX

## Learning objectives

By the end of this lecture, students should be able to:

- Structure a LaTeX document (`\documentclass`, sections, packages)
- Typeset inline and display math
- Include tables, figures, and references
- Manage a bibliography with `biblatex` or `bibtex`
- Compile locally with `tectonic`/`latexmk` or on Overleaf
