# Week 6 — Control flow

## Learning objectives

By the end of this lecture, students should be able to:

- Write `if`/`elif`/`else` branches
- Write `while` and `for` loops
- Use `range`, `break`, `continue`, and `enumerate`
- Combine conditions with `and`, `or`, `not`
- Recognize common loop patterns (accumulator, sentinel, early exit)
